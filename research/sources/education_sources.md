## Единая схема и иерархия

| Рейтинг | Определение из `00_research_plan.md` | Допустимое использование |

### Правила интерпретации

1. **Grade claim-relative.** Официальная product page может быть A для цены/функции и C для эффективности. Guidance/law может быть A для текста требования, но не имеет causal learning status.
2. **Causal hierarchy.** Для learning claim приоритет: preregistered/peer-reviewed randomized field evidence → качественный meta-analysis/systematic synthesis контролируемых исследований → ограниченный experiment/quasi-experiment → observational/vendor analytics → marketing.
3. **External evidence ≠ Arena effect.** Даже A-meta-analysis не подтверждает конкретную реализацию, российскую школьную аудиторию, delayed transfer или отсутствие subgroup harm.
4. **Outcome separation.** Activity/retention-in-product, motivation, current assisted performance, delayed unaided learning, competition rating и mastery — разные outcomes.
5. **Version discipline.** Corrigendum/superseding report имеет приоритет; historical launch page не используется как current implementation.
6. **Access.** Каждая строка имеет `accessed=2026-07-20`. На этом шаге URLs перенесены из финальных проверенных ledger без нового web research.
